# GEO + SEO reference checklist

## Page-level review
- [ ] HTTP status and redirect chain are correct.
- [ ] Public production/staging/preview environment is identified.
- [ ] Indexing directive is intentional for this environment.
- [ ] Canonical URL is absolute, correct and self-consistent with sitemap/OG URL.
- [ ] Title is unique, descriptive and accurate.
- [ ] Meta description accurately summarizes visible content.
- [ ] HTML language is set correctly.
- [ ] Main heading and content hierarchy are understandable.
- [ ] Important content is available in crawlable rendered HTML.
- [ ] Internal links use meaningful anchor text and resolve.
- [ ] Images have appropriate alt text; decorative images have empty alt.
- [ ] Structured data is valid and matches visible facts.
- [ ] Sources, authorship and dates are real and appropriate.
- [ ] Mobile rendering and performance are acceptable.

## Site-level review
- [ ] robots.txt is reachable and policy is intentional.
- [ ] Sitemap contains only canonical, indexable, successful URLs.
- [ ] Sitemap is discoverable through robots.txt.
- [ ] No accidental noindex, disallow or canonical conflicts.
- [ ] Redirects and 404s behave correctly.
- [ ] No duplicate or thin doorway pages.
- [ ] Search Console/Bing verification is owner-controlled.
- [ ] Privacy/licensing decisions for AI crawlers are documented.

## Measurement
Record date, environment, exact URL, crawler/engine, query or prompt, observation, evidence link and next action. Do not report an AI citation as a guaranteed outcome or infer rankings from a single prompt check.
