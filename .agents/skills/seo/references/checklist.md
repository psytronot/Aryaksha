# Conventional SEO audit checklist

## Environment and indexing
- [ ] Production, staging, preview and local origins identified.
- [ ] Public route status codes and redirect chains checked.
- [ ] Preview noindex/disallow protections preserved.
- [ ] Canonical host is approved and verified.
- [ ] Meta robots and X-Robots-Tag directives agree with intent.
- [ ] robots.txt policy is deliberate (not treated as access control).
- [ ] Sitemap contains only canonical, intended indexable URLs.
- [ ] Sitemap is reachable and referenced appropriately.

## Page-level SEO
- [ ] Unique, accurate title and meta description.
- [ ] Correct document language and semantic heading structure.
- [ ] One clear page purpose/search intent.
- [ ] Important content is present in crawlable rendered HTML.
- [ ] Internal links are descriptive and resolve.
- [ ] No thin, doorway, duplicated or keyword-stuffed pages.
- [ ] Structured data is valid and reflects visible facts.
- [ ] Images have descriptive filenames where useful, optimized formats/dimensions and appropriate alt text.

## Page experience
- [ ] Mobile layout works at narrow and wide widths.
- [ ] No horizontal overflow or obstructive interstitials.
- [ ] Core Web Vitals/performance checked with available evidence.
- [ ] Keyboard navigation, contrast and accessible semantics preserved.
- [ ] Images/fonts/scripts are not unnecessarily blocking or oversized.

## Content and authority
- [ ] Claims are accurate, useful and supported.
- [ ] Authors, dates, credentials, awards and reviews are real.
- [ ] Sources are primary or otherwise credible.
- [ ] No paid/link-scheme, spam-directory or deceptive outreach tactics.
- [ ] Content freshness reflects actual changes, not cosmetic date updates.

## Measurement
- [ ] Search Console/Bing data used only with authorized access.
- [ ] Measurement window, URLs, queries and dates recorded.
- [ ] Lab performance metrics distinguished from field metrics.
- [ ] Outcomes and limitations reported without ranking guarantees.
